
# Text RPG: The Battle Arena

## Project Description
A simple text-based RPG developed in Python using
Object-Oriented Programming concepts.

## Features
- Three playable heroes: Warrior, Mage, and Paladin
- Three enemies: Goblin, Orc, and Dragon
- Turn-based combat
- Special attacks and resource management
- Healing potions
- Character health and status display
- Paladin Method Resolution Order demonstration

## OOP Concepts
- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Multiple Inheritance
- Method Overriding
- Polymorphism
- Composition
- Class Variables
- Class Methods
- super() and Method Resolution Order

## Requirements
Python 3.10 or newer

## How to Run
Open a terminal in the project root directory.

Run:

python main.py
